## Descripción del problema y datos

En este proyecto vamos a utilizar un dataset conocido como “Hotel Booking Demand” para intentar predecir si un cliente va a cancelar su reserva o no. El objetivo principal de este tipo de proyectos suele ser minimizar las cancelaciones o, si no es posible, anticiparlas para poder reasignar los recursos del hotel de manera más eficiente.

Este dataset se ha tomado de Kaggle y se conoce popularmente como “Hotel Cancellations” o “Hotel Booking Demand Dataset”. Contiene información sobre reservas realizadas en dos hoteles diferentes: un hotel urbano (city hotel) y un hotel de tipo resort (resort hotel), ambos gestionados por la misma cadena hotelera. Los datos cubren un período de dos años y recopilan información detallada sobre las características de las reservas.

## Instrucciones para ejecutar el proyecto

2. Preprocesamiento de datos
3. Entrenamiento de modelos
4. Evaluación de modelos
5. Generación de evidencias
6. Generación de tag con release
7. Compilación de la imagen Docker
